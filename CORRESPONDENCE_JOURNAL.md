---

### Правила ведения журнала (обязательны для обеих сторон)

1. Каждое новое сообщение добавляется **строго в конец** файла.
2. Сообщения не удаляются, не переписываются и не «исправляются задним числом».
3. Каждое сообщение начинается с заголовка следующего формата:

```
---
**[YYYY-MM-DD HH:MM TZ]** | От: [Имя] | Кому: [Имя] | Тип: [СООБЩЕНИЕ / ОТЧЁТ / АУДИТ / ЗАДАНИЕ / ЗАМЕЧАНИЕ / ПРИНЯТИЕ / ВОЗВРАТ]
**Тема:** краткая тема
```

4. После заголовка идёт тело сообщения.
5. В конце сообщения рекомендуется ставить разделитель `---` или просто оставлять пустую строку перед следующим заголовком.
6. Допускаются теги внутри текста: `[REAL]`, `[SIM]`, `[PROD-READY]`, `[NEEDS-WORK]`, `[SECURITY-CRITICAL]`, `[ЭТАП-N]` и т.д.
7. Этот журнал является основным каналом рабочей переписки по этапам. Отдельные «письма» вне журнала не создаются.
