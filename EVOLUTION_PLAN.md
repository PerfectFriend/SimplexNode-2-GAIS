## Продуктовая рамка (зафиксировано 2026-11-11)

**Главный экран = чат в стиле Telegram.**  
Нижняя панель с кучей кнопок больше не является центром навигации.  
Из чата открывается единое меню (drawer / side panel / overflow), где живут:
- список чатов / контактов
- сейф (Vault)
- сеть / нода / Tor
- файлы / облако
- настройки
- прочее

**Принципы UI:**
1. Эффективное использование пространства (минимум постоянных панелей).
2. Унификация: привычные паттерны (Telegram-like chat, Gboard-like keyboard).
3. Клавиатура ввода — по раскладке и габаритам максимально близка к стандартной Gboard, чтобы не переучивать пальцы.
4. Украшательство (темы, скины, обои, орнаменты) — **только после** закрытия функционального ядра.
5. «Радиоточка» как индикатор здоровья ноды: играет = трафик/сеть в порядке; замолчало = сигнал тревоги.

## Этап 6 — UI Core Refactor (Telegram-style shell)
**Статус:** 🔒 Заблокирован до закрытия функциональных этапов 4–5 (можно частично параллелить после Этапа 4 по согласованию)

Цели:
1. **Главный экран = Chat** (Telegram-like):
   - список диалогов / текущий чат на весь экран
   - минимум постоянных chrome-элементов
2. **Единое меню** (drawer / modal / overflow) вместо нижней навигации с множеством кнопок:
   - Чаты
   - Сейф (Vault)
   - Сеть / Нода / Tor
   - Файлы / Облако
   - Настройки
   - Логи / Диагностика
3. Убрать или сильно сжать нижний navigation bar как основной способ перемещения.
4. Navigation Compose / единый back-stack, предсказуемые переходы.
5. Адаптация существующих экранов (Vault, Network, Logs, FileSharing) под новое меню без потери функциональности.

**Критерии приёмки:**
- При запуске пользователь попадает в чат, а не в «панель кнопок».
- Все основные разделы доступны из одного меню.
- Пространство экрана используется заметно эффективнее.
- Нет регрессии критичных функций (vault unlock, Tor toggle, SMP send).

## Этап 7 — Клавиатура и ввод (Gboard-like)
**Статус:** 🔒 Заблокирован до Этапа 6

Цели:
1. Встроенная / используемая клавиатура по раскладке и габаритам максимально близка к Gboard (привычные зоны, размеры клавиш, поведение shift/symbols).
2. Не заставлять пользователя переучивать мышечную память.
3. Корректная работа с полями чата, поиском, вводом в сейф.

*Примечание: если системная клавиатура уже устраивает — зафиксировать решение и не плодить кастом без нужды. Кастом только если есть сильная причина (privacy / offline / consistent look).*
