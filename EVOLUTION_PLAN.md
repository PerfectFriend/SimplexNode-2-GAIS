## Продуктовая рамка

1. **Главный экран = чат** (Telegram-style), единое боковое меню.
2. **Ввод = ТОЛЬКО встроенная клавиатура приложения.**  
   - Системная IME (Gboard / любой vendor keyboard) **не используется** как интерфейс ввода.  
   - Встроенная клавиатура **копирует эргономику Gboard** (раскладка, размеры, зоны больших пальцев, shift/symbols), чтобы не переучивать пальцы.  
   - Все нажатия остаются внутри процесса приложения → минимальная поверхность для keylogger/телеметрии ОС и Google.  
   - Режим «максимально автономной ноды»: гуглу ввод не доверяем.
3. **Корень доверия = BIP-39 master seed.**  
   Один ключ владельца → детерминированная деривация всего (vault, tor, smp, xftp, p2p, wallet, node/{index}).
4. **Флот нод:** один master seed → N нод + единый центр мониторинга/управления.
5. **Онбординг UX-донор:** `PerfectFriend/BIP39-Onboarding-pipeline`.
6. **Украшательство / радиоточка** — после key/fleet ядра.

## Этап 7 — Клавиатура и ввод
**Статус:** 🔄 НА ДОРАБОТКЕ (коррекция владельца 2026-11-11)

### Было (ошибочно принято)
Системная Gboard как основной ввод + Air-Gap как опция.

### Стало (обязательно)
1. **Полностью убрать системную IME** из пользовательских полей ввода (chat, PIN, seed, search, commands).
2. **Встроенная клавиатура** — единственный способ ввода:
   - эргономика и габариты ≈ Gboard (RU/EN, symbols, shift, backspace, enter/send);
   - все события клавиш обрабатываются только внутри app;
   - не вызывать `InputMethodManager.showSoftInput` для секретных и основных полей.
3. Поля, где раньше открывался Gboard → фокус открывает **in-app keyboard panel**.
4. Особенно критично для: BIP-39 seed, PIN, panic PIN, chat message box.
5. `FLAG_SECURE` на экранах с seed/PIN сохраняется.

**Критерии приёмки (обновлённые):**
- В основных сценариях системная клавиатура не появляется.
- In-app keyboard позволяет нормально набирать RU/EN и символы.
- Эргономика узнаваемо «как Gboard», без ломания мышечной памяти.
- Seed/PIN ввод не уходит в vendor IME.
- Сборка зелёная + отчёт.
